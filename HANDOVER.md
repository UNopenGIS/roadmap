# Handover Guide - UN Open GIS Initiative

## Project Overview
This repository contains presentation materials and documentation for the UN Open GIS Initiative monthly meetings, dating from 2025 onwards.

## Key Files
- `UN_OpenGIS_Presentations_2025.md` - 2025 meeting presentations
- `UN_OpenGIS_Presentations_2026.md` - 2026 meeting presentations
- `Presentation/` - Directory containing PDF files organized by year and date
